# Third-party notices

## Icons8 concept icons

The private visual-concept build bundles selected PNG files from the Icons8
Windows 11 Color and Windows 11 Outline icon families for general
user-interface controls. These temporary concept assets are intended to be
replaced by commissioned original artwork before public distribution. Usage
information and an exact source mapping are included in the release package.

- Project: https://icons8.com/
- License information: https://icons8.com/license
- Local usage notice: `resources/icons/actions/LICENSE.icons8.txt`
- Source mapping: `resources/icons/actions/SOURCES.icons8.txt`

Icons8 assets are not used for QGIS map-layer symbology or layer-specific
icons.
